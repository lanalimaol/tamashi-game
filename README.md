# 🎮 Sobre o Jogo

Jogo de plataforma 2D para PC, desenvolvido em **2021** como projeto final de um curso introdutório de desenvolvimento de jogos 2D.

---

## ⚠️ Estado atual do projeto

O projeto ainda está **desorganizado**. O prazo de entrega na época era muito curto para o tamanho do jogo que a equipe tinha planejado, então muita coisa ficou para depois. Ao explorar os arquivos, você vai encontrar:

- 🖼️ Imagens duplicadas com nomes diferentes
- 🔊 Arquivos de áudio soltos na raiz do projeto
- 🐞 Bugs na cena final (e, possivelmente, em outros pontos do jogo 😅)

---

## 🛠️ Próximos passos

A ideia agora é dar uma nova vida ao projeto:

- [ ] Reestruturar o projeto
- [ ] Reorganizar pastas e arquivos
- [ ] Remover arquivos duplicados
- [ ] Fazer o debug e corrigir os bugs conhecidos, com atenção especial à cena final

---

## 🎨 Créditos

- **Sprites, cenários e roteiro:** criados do zero pela equipe
- **Trilha sonora:** músicas de jogos já conhecidos (não são de autoria da equipe)
- **Mapas:** construídos com o auxílio de bibliotecas de terceiros
